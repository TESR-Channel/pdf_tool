# TESR PDF Editor

> **ใช้งานได้เลยที่ 👉 https://tesr-channel.github.io/pdf_tool/**
> ไม่ต้องติดตั้ง ไม่ต้องสมัคร ไฟล์ไม่ออกจากเครื่อง

PDF Editor สำหรับทีม TESR Co., Ltd. (Thai Embedded System and Robotics) — ทำงานบน browser 100% ไม่มี server
รองรับ **มือถือ / แท็บเล็ต / คอมพิวเตอร์** ทุกขนาดหน้าจอ และติดตั้งเป็นแอปบนหน้าจอโฮมได้

## วิธีใช้ (3 ขั้นตอน)
1. เปิด https://tesr-channel.github.io/pdf_tool/ แล้ววางไฟล์ PDF (หรือรูป JPG/PNG — จะถูกแปลงเป็นหน้า PDF) เลือกหลายไฟล์ = รวมไฟล์
2. แก้ไขด้วย toolbar ด้านบน / panel **เครื่องมือทั้งหมด** ด้านซ้าย
3. กด **ดาวน์โหลด ▾** หรือ **พิมพ์**

**บนมือถือ:** ปุ่มมุมซ้ายบน = หน้า/เครื่องมือ · ปุ่มลอยขวาล่าง = ตัวเลือกของเครื่องมือ · ใช้ 2 นิ้วซูมเข้า-ออก แล้วเลื่อนซ้าย-ขวาได้
**ติดตั้งเป็นแอป:** Chrome/Safari → เมนู → "เพิ่มไปยังหน้าจอโฮม"

## ใช้งานเร็วแบบ Acrobat
- **ดับเบิลคลิก**ข้อความบนหน้า → พิมพ์แก้ตรงนั้นทันที (Esc / คลิกที่อื่น / Ctrl+Enter เพื่อจบ) · ดับเบิลคลิกที่ว่าง → เพิ่มข้อความใหม่ตรงนั้น · เครื่องมือ "ข้อความ" แตะแล้วพิมพ์ได้เลย
- **คลิกขวา** (มือถือ: กดค้าง) → เมนู: แก้ไข / ตัด / คัดลอก / วางที่นี่ / ทำสำเนา / คัดลอกไปทุกหน้า / นำขึ้นหน้า-ส่งไปหลัง / ลบ · บนที่ว่าง: เพิ่มข้อความ-หมายเหตุ-ลายเซ็น-ตรายาง TESR-วันที่ตรงนั้น / หมุน-ทำสำเนา-แทรก-ลบหน้า / ดาวน์โหลด / พิมพ์
- **คีย์ลัด**: Ctrl+C / X / V คัดลอก-ตัด-วาง · Ctrl+D ทำสำเนา · Ctrl+S ดาวน์โหลด PDF · Ctrl+P พิมพ์ · Ctrl+F ค้นหา · Ctrl+Z / Y เลิกทำ-ทำซ้ำ · Ctrl + / − / 0 ซูม · Delete ลบ · Enter แก้ข้อความที่เลือก · ลูกศรเลื่อนทีละ 1 pt (Shift = 10) · V T H B E U I N G K R สลับเครื่องมือ

## หน้าตาแบบ Acrobat
- แถบเมนู **เครื่องมือทั้งหมด / แก้ไข / แปลง / ลงนาม** + ช่อง **ค้นหาข้อความในเอกสาร** (highlight ทุกจุดที่พบ)
- Panel ซ้าย: แท็บ **หน้า** (thumbnail: ลากสลับ / หมุน / ทำสำเนา / ลบ) และ **เครื่องมือทั้งหมด**
- Rail ขวา: เลขหน้า / เลื่อนหน้า / หมุน / ซูม

## เครื่องมือ
| กลุ่ม | เครื่องมือ |
|---|---|
| ใส่บนหน้า | ข้อความ (ไทยได้) · ไฮไลท์ · ปากกา · ยางลบ/ปิดทับ · รูปทรง (สี่เหลี่ยม/วงรี/เส้น/ลูกศร) · รูปภาพ · **หมายเหตุ** (PDF Comment จริง) · **ปกปิดข้อมูล / Redact** (ลบเนื้อหาใต้กรอบออกจากไฟล์จริง) |
| ลงนาม | ลายเซ็น (วาด/อัปโหลด) · **ตราประทับ** แบบข้อความ (อนุมัติ/ตรวจแล้ว/ลับ/…) และ **ตรายาง TESR** (โลโก้แบบหมึกตรายาง เลือกสีแดง/น้ำเงิน/ดำ/เขียว) · ใส่วันที่ภาษาไทย |
| ทั้งเอกสาร | ลายน้ำ (ข้อความ / โลโก้ TESR / รูป) · เลขหน้า |
| จัดหน้า | ลากสลับ · หมุน · ทำสำเนา · ลบ · เพิ่มหน้าจากไฟล์อื่น (รวม PDF) · หน้าว่าง |
| แปลง | PDF→JPG/PNG · PDF→TXT · **PDF→Word (.docx)** · **OCR ไทย/อังกฤษ** (ทำ PDF สแกนให้ค้นหา/คัดลอกได้) · ลดขนาด · แยกไฟล์ (ZIP) |
| ไฟล์ | ดาวน์โหลด · แชร์ (LINE/อีเมล บนมือถือ) · พิมพ์ · Metadata · Undo/Redo (Ctrl+Z / Ctrl+Y) |

ทุกวัตถุที่ใส่ลงไป (รวมลายน้ำ/เลขหน้า/ตรายาง) เลือก ย้าย ปรับขนาด แก้ไข หรือลบได้ก่อนดาวน์โหลด

## ความเป็นส่วนตัว
ประมวลผลใน browser ทั้งหมด (pdf-lib + PDF.js) ไม่มีการอัปโหลดไฟล์ไปยัง server ใดๆ
ยกเว้น OCR ที่จะดาวน์โหลด *ข้อมูลภาษา* จาก CDN ครั้งแรก (~10 MB) — ตัวไฟล์เอกสารยังอยู่ในเครื่อง

## สำหรับผู้ดูแล (Deploy)
Repo นี้เป็น static site — GitHub Pages ตั้งค่า **Settings → Pages → Source: Deploy from a branch → `main` / (root)**
ไฟล์หลัก: `index.html`, `app.js` (แกนหลัก) + `patch-responsive.js` (จอเล็ก) + `ux.js` (ดับเบิลคลิกแก้ทันที / คลิกขวา / คีย์ลัด — โหลดตามลำดับนี้), `logo.png` (โลโก้ ใช้ทั้ง UI / ตรายาง / ลายน้ำ), `Loma.otf` (ฟอนต์ไทยสำหรับ OCR text layer), `fontkit.umd.min.js`, `manifest.json`
เปิดไฟล์จาก URL ได้ด้วย `?file=path/to/file.pdf` (ต้องอยู่ใน repo เดียวกันหรืออนุญาต CORS)

## Stack
pdf-lib + @pdf-lib/fontkit · PDF.js · JSZip · Tesseract.js (OCR, โหลดเมื่อใช้) · Google Fonts Kanit + Sarabun · ฟอนต์ Loma (TLWG)

## ข้อจำกัด
- ยังใส่รหัสผ่าน/เข้ารหัส PDF ไม่ได้ และไม่มีการขอลายเซ็นผ่านอีเมล (ต้องมี server)
- แก้ "ข้อความเดิม" ใน PDF โดยตรงไม่ได้ — ใช้ยางลบปิดทับแล้วพิมพ์ทับแทน
- "ลดขนาด" และ "Redact" จะแปลงหน้านั้นเป็นภาพ ข้อความจะเลือก/ค้นหาไม่ได้ (ทำ OCR ต่อได้)
- ไฟล์ใหญ่มาก (>100 MB) อาจช้าบนมือถือ
