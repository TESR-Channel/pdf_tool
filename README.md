# TESR PDF Editor

PDF Editor สำหรับทีม TESR Co., Ltd. — ทำงานบน browser 100% (ไม่มี server, ไฟล์ไม่ออกจากเครื่อง)
รองรับมือถือ / แท็บเล็ต / คอมพิวเตอร์ และติดตั้งเป็นแอปบนหน้าจอโฮมได้ (PWA manifest)

## วิธีใช้
1. วางไฟล์ PDF (หรือรูป JPG/PNG — จะถูกแปลงเป็นหน้า PDF) ที่หน้าแรก เลือกหลายไฟล์ได้ = รวมไฟล์
2. แก้ไขใน editor ด้วย toolbar ด้านบน แล้วกด **ดาวน์โหลด** หรือ **พิมพ์**

## เครื่องมือใน editor
| กลุ่ม | เครื่องมือ |
|---|---|
| ใส่บนหน้า | ข้อความ (ไทยได้) · ไฮไลท์ · ปากกา · ยางลบ/ปิดทับ · รูปทรง (สี่เหลี่ยม/วงรี/เส้น/ลูกศร) · รูปภาพ · ลายเซ็น (วาด/อัปโหลด) |
| ทั้งเอกสาร | ลายน้ำ (ข้อความ / โลโก้ TESR / รูป) · เลขหน้า |
| จัดหน้า (แถบซ้าย) | ลากสลับลำดับ · หมุน · ทำสำเนา · ลบ · เพิ่มหน้าจากไฟล์อื่น · หน้าว่าง |
| ดาวน์โหลด ▾ | PDF · เฉพาะบางหน้า / แยกไฟล์ (ZIP) · ลดขนาด · แปลงเป็น JPG/PNG · ดึงข้อความ TXT · แก้ Metadata |
| อื่นๆ | เลิกทำ/ทำซ้ำ (Ctrl+Z / Ctrl+Y) · ซูม · พิมพ์ · ลากไฟล์มาวางใน editor เพื่อรวมไฟล์ |

ทุกวัตถุที่ใส่ลงไป (รวมลายน้ำ/เลขหน้า) เลือก ย้าย ปรับขนาด แก้ไข หรือลบได้ก่อนดาวน์โหลด

## Deploy บน GitHub Pages
1. สร้าง repo แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปที่ branch `main`
2. **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save
3. เปิดที่ `https://<org>.github.io/<repo>/`

เปิดไฟล์จาก URL ได้ด้วย `?file=path/to/file.pdf` (ไฟล์ต้องอยู่ใน repo เดียวกันหรืออนุญาต CORS)

## โลโก้
`logo.png` ใช้ใน header, หน้าแรก, favicon, manifest และตัวเลือก "โลโก้ TESR" ในลายน้ำ

## Stack
pdf-lib (สร้าง/แก้ PDF) · PDF.js (เรนเดอร์/ดึงข้อความ) · JSZip · Google Fonts Kanit + Sarabun
ข้อความที่ใส่ถูกเรนเดอร์ผ่าน canvas จึงรองรับภาษาไทยและทุกฟอนต์

## ข้อจำกัด
- ยังใส่รหัสผ่าน/เข้ารหัส PDF ไม่ได้ (pdf-lib ไม่รองรับ)
- แก้ "ข้อความเดิม" ใน PDF โดยตรงไม่ได้ — ใช้ยางลบปิดทับแล้วพิมพ์ทับแทน
- "ลดขนาด" แปลงหน้าเป็นภาพ ข้อความจะเลือก/ค้นหาไม่ได้
- ไฟล์ใหญ่มาก (>100 MB) อาจช้าบนมือถือ
